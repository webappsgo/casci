# Backend Rules (PART 9, 10, 11, 32)

⚠️ **These rules are NON-NEGOTIABLE. Violations are bugs.** ⚠️

## CRITICAL - NEVER DO
- Include `"cookies"` in a version-change `Clear-Site-Data` purge — it would destroy sessions and stored preferences; only the session-revoke purge includes cookies
- Cast user-controlled file content (pastes, uploads, HTML/SVG/XML) to `template.HTML` or otherwise treat it as trusted browser content
- Shell out with raw user content, filenames, refs, or repo metadata; run hooks/build steps/interpreters/git-checkout logic on untrusted content outside an explicitly sandboxed feature
- Return `installation_secret` or any project-level secret in an API response, admin UI, or log — even to admins (show "configured"/fingerprint/rotation-age only)
- Emit the `Server-Timing` header in production — Tier-3 internal-latency info, debug-mode only
- Emit the deprecated `Public-Key-Pins` (HPKP) header — never; lockout risk
- Return user-controlled fields back in a CSP report response body
- Redirect admin login to user routes or user login to admin routes
- Let anything override `/.well-known/acme-challenge/{token}` or `/.well-known/change-password`, list a directory index under `/.well-known/`, or expose secrets/internal config there
- Log the `{security_id}` rotating token anywhere except the `security.txt` `Contact:` line
- Persist a security report body in plaintext — always encrypted (PGP if configured, else AES-256-GCM with `server.security.encryption_key`)
- Log a password, even hashed, in the audit log
- Use system Tor or system i2pd — the app starts and owns its own dedicated process for each
- Use Tor's default ports (9050/9051) — always runtime-detected localhost ports, never hardcoded or saved

## CRITICAL - ALWAYS DO
- Return errors in the standard response format with the defined error codes and HTTP status mapping
- Attempt self-healing for all recoverable errors before considering maintenance mode
- Apply cache TTL defaults, key naming, and invalidation rules consistently; version-bust assets on deploy
- Make schema updates idempotent; treat cluster schema updates as a coordinated, version-gated operation
- Auto-detect single-instance vs cluster mode; never let an agent become a cluster node or a cluster node act as an agent
- Apply the Public Endpoint Safety Principle's three-tier model — Tier 1 never public, Tier 2 always public-safe, Tier 3 debug-only, stripped in production by the output-sanitization middleware
- Redact any field whose name contains `secret`, `key`, `password`, or `token` at the log layer
- Apply all configured security headers (CSP, cross-origin isolation, privacy-signal, `Sec-Fetch-*` validation) per the header config
- Enable the Tor hidden service automatically whenever the `tor` binary is found — no enable/disable toggle
- Keep Tor/I2P directories under the app's own `{config_dir}/{data_dir}/{log_dir}` — never separate hardcoded paths
- Log all audit events required by the "ALWAYS Log" list (admin actions, security events, token events, cluster events) with IP and actor, never the secret value itself

## TERMINOLOGY
| Term | Meaning |
|------|---------|
| `installation_secret` | Cluster-wide secret, generated by first node, delivered via secure join handshake, never exposed |
| Tier 1/2/3 (Public Endpoint Safety) | Never-public / always-public-safe / debug-only response field classes |
| `{security_id}` | Rotating one-shot token gating the coordinated-disclosure contact endpoint |
| Model A / Model B (I2P) | App-managed dedicated i2pd process vs connecting to an existing router's SAM bridge |

## QUICK REFERENCE
- Errors: standard envelope + defined codes; self-heal before maintenance mode.
- Cache: driver-based, TTL defaults, version-busted assets, no `"cookies"` in version purges.
- Cluster: auto-detected, heartbeat/failover, secret rotation anti-split-brain, agents excluded.
- Security: three-tier public-safety model, full header set, redacted secrets everywhere, encrypted-at-rest security reports.
- Overlay networks: Tor auto-on when binary present (own process, runtime ports only); I2P opt-in (Model A owns its i2pd, Model B uses SAM).
